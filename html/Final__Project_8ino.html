void BleTransmit_Task ( void *  pvParameter)

FreeRTOS task running on Core 0 acting as a BLE Client to transmit matrix data.

Scans for the target BLE peripheral, establishes a connection, adjusts the MTU size, and waits for frames in the FreeRTOS queue to transmit as a 64-byte ASCII payload.

◆ JoystickCheck_Task()

void JoystickCheck_Task ( void *  pvParameter)

FreeRTOS task running on Core 1 to monitor joystick inputs and update the drawing matrix.

Reads analog inputs from the joystick, updates the internal coordinate trackers, illuminates the corresponding LED, and packages the final matrix frame into a queue upon button press.

Parameters
pvParameterPointer to FreeRTOS task parameters (unused).
Returns
