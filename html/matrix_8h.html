This function contains the main path finder algorithm used to traverse the received 2D matrix and draw the image.

Uses a recursive depth first search approach to explore the 2D LED matrix received via BLE, setting the servos to their appropiate angle on every step. Points explored are marked and set to 2. Order of exploration follows the cardinal directions:

  1. Top
  2. Right
  3. Down
  4. Left

    led_matrix2D matrix currently being explored
    curr_rowIndex of current row the function is exploring
    curr_columnIndex of current column the function is exploring
