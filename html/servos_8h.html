◆ set_angle_servo_1()

void set_angle_servo_1 ( uint8_t  angle)

Moves servo 1 to the specified angle.

The Micro Servo 9g requires a PWM signal at 50 Hz as an input to control the angle of the motor. Each duty cycle value between 2.5% and 12.5% maps to an angle between 0° and 180° respectively. A simple linear function was used to map this values, its slope and intercept are defined as SLOPE_SERVO and INTERCEPT_SERVO
